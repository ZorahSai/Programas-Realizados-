# Meus Projetos e Estudos em Python

Bem-vindo ao meu repositório de desenvolvimento em Python! 

Este espaço serve como meu portfólio e diário de aprendizado, documentando minha evolução. Aqui você encontrará desde algoritmos de lógica básica até aplicações estruturadas usando Orientação a Objetos e interfaces gráficas.

## Estrutura do Repositório

O repositório está organizado para refletir a progressão de complexidade dos códigos:

* **`01_Fundamentos/`**: Exercícios focados em lógica de programação, estruturas de repetição, condicionais e manipulação de variáveis.
* **`02_Exercicios_Academicos/`**: Desafios e listas de exercícios que envolvem matemática aplicada, funções e validações complexas.
* **`03_Orientacao_a_Objetos/`**: Projetos que aplicam os pilares da POO (classes, métodos, encapsulamento), como o sistema de gerenciamento de estudantes.
* **`04_Projetos_Avancados/`**: Sistemas mais completos, como o **SmartPark** (gerenciador de estacionamento) e aplicativos desktop com interface gráfica (GUI) construídos com bibliotecas como o Tkinter (ex: `Senha_Chamador.py`).

## Tecnologias e Conceitos Utilizados

* **Linguagem:** Python 3.x
* **Paradigmas:** Programação Estruturada e Orientação a Objetos (POO)
* **Bibliotecas:** Tkinter (Interfaces Gráficas), `math`, `random`.
* **Arquitetura:** Modelagem de classes, getters/setters e separação de responsabilidades (como visto no projeto SmartPark).
